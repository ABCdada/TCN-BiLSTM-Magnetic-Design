01

Quick start

Select one of the A-E material checkpoints, prepare a synchronized 1,000-sample window, specify temperature and the known-H interval, and send the request to the window-prediction endpoint. The model returns a full H sequence whose masked target interval is produced in one forward pass.

Reference gridAt 16 MHz, a 1,000-sample window spans 62.5 µs. Keep physical units and sampling order consistent with training.

02

Input data and units

FieldUnit / typeRequirement
Btesla, float[1000]Complete synchronized flux-density sequence.
temperature°C, scalar or float[1000]Scalar is broadcast across the window; released-data coverage is 25–70 °C.
known_HA/m, prefix or nullable float[1000]Measured history; unknown target may be omitted or null. Material C instead requires its trained one-point zero placeholder.
modestring100-900, 500-500, 900-100, or 1-999.
sampling_rate_hzHz16,000,000 for the released checkpoints.

dB and the binary mask are formed inside the inference pipeline. Material E additionally derives and normalizes ddB, the second discrete flux increment. The mask separates the measured H history from the interval to be reconstructed.

03

History-to-prediction modes

100 / 900

Long reconstruction interval with limited magnetic history. This is the most demanding standard condition.

500 / 500

Balanced history and target intervals for medium-horizon transient reconstruction.

900 / 100

Short continuation when the preceding magnetic trajectory is well established.

1 / 999

Cold-start condition intended for data without an effective historical H trajectory.

04

HTTP API

List checkpoints

GET /api/models

Predict one window

POST /api/predict-window
Content-Type: application/json

{
  "material": "A",
  "B": [0.0012, 0.0018, "... 1000 values"],
  "temperature": 25,
  "known_H": [0.0, 1.2, "... known prefix"],
  "mode": "100-900",
  "sampling_rate_hz": 16000000
}

The response contains the full reconstructed H sequence, known and predicted portions, model metadata, and energy-related quantities when their calculation is applicable.

Predict a longer sequence

POST /api/predict-sequence

This endpoint applies overlapping windows to an N-point sequence. Window-to-window use is distinct from one-pass inference inside each window; inspect boundary behavior when using long trajectories.

05

Circuit-solver integration

  1. 1
    Initialize the operating point

    Set excitation, material, temperature, time step, turns, effective area, and magnetic path length.

  2. 2
    Reconstruct the flux-density window

    Integrate the magnetic-core induced voltage after removing winding-resistance, leakage-inductance, and relevant parasitic drops; then form B and dB on the 16 MHz sample grid.

  3. 3
    Infer the masked H interval

    Pass B, its material-specific derived increments, temperature, the measured or solver-provided H history, and its mask through the model in one forward call.

  4. 4
    Return the magnetic block state

    Merge the known history and prediction, then convert H to magnetic-branch current. Use it to post-process a voltage-defined window or inside an external block/outer-iteration scheme; the bidirectional model is not a causal one-timestep feedback element.

Validation dataThe circuit API accepts an optional full reference_current array for accuracy metrics. A current history prefix is sufficient for inference but is not a validation reference. Supply reference_loss_density to reproduce the paper/challenge energy-error denominator.
Geometry scopeThe direct Ae/le conversion assumes a near-uniform toroidal or equivalent magnetic path. Gapped, hybrid-material, strongly nonuniform, or leakage-dominated structures require a segmented magnetic circuit or field solver to provide local B and H.

06

Energy interpretation

The discrete trajectory integral based on H and B can represent different quantities depending on the interval. Over a closed path it gives the cumulative enclosed energy; this equals dissipated energy density per cycle only when the record contains exactly one magnetic period. Over a non-closed transient interval it also includes reversible energy exchange and the change in stored magnetic energy. Do not label every partial-window integral as irreversible core loss.

07

Limitations and responsible use

  • The released checkpoints are material-specific and should not be treated as universal constitutive laws.
  • The 16 MHz interval is part of the learned representation. Resampled data require explicit dB/dt handling and retraining or fine-tuning.
  • Temperature should remain within the coverage of the material's training data.
  • Predictions outside the measured excitation, B, DC-bias, or saturation range are extrapolations.
  • The demonstration supports circuit integration but does not replace independent experimental validation or calorimetric loss measurement.
  • Check normalization metadata and checkpoint compatibility before comparing models.
