Getting Started

Welcome to AI Magnetic Design

AI Magnetic Design is a comprehensive platform for magnetic component design and analysis. The platform provides two complementary workflows:

Test Center

New

For rapid AI-powered analysis of measured magnetic data. Upload B-field CSV files (16 MHz sampling) to predict H-field and evaluate the interval magnetic-energy exchange rate density.

Best for: Testing 3C92, 3C95, FEC014, and T37 trajectories and high-speed single-sequence analysis

Design Center

For interactive simulation and design of magnetic components using dedicated 3C92, 3C95, FEC014, and T37 native cold-start models. Configure operating conditions, choose a material, adjust core geometry, and visualize real-time behavior.

Best for: New component design, topology simulation, parameter optimization

System Requirements

  • Modern web browser (Chrome, Firefox, Safari, Edge)
  • JavaScript enabled
  • Internet connection to load Tailwind CSS and chart libraries from public CDNs
  • Recommended: 1920x1080 or higher resolution

Test Center New Feature

Overview

The Test Center provides rapid AI-powered analysis for 3C92, 3C95, FEC014, and T37. Upload a magnetic flux-density sequence sampled at 16 MHz, select the material, and obtain its H-field prediction and interval magnetic-energy exchange rate density. For a closed steady-state B-H cycle, this density can be interpreted as core-loss density.

Workflow

  1. Upload B Data: Import a CSV file containing magnetic flux density (B) measurements (single line, comma-separated)
  2. Set Temperature: Adjust operating temperature (25-70°C) using the slider; changes trigger automatic re-prediction
  3. Select Material: Choose 3C92, 3C95, FEC014, or T37; each dedicated cold-start model requires only one zero H placeholder
  4. AI Prediction: The system automatically sends data to the AI model and retrieves H-field predictions
  5. View Results: Analyze the reconstructed B-H trajectory and interval magnetic-energy exchange rate density

Data Format Specification (B.csv)

The input file must be a single-line CSV file with comma-separated values representing magnetic flux density:

0.0012,0.0015,0.0018,0.0021,0.0024,...,0.0010
  • Format: Single row only, no headers, comma-separated
  • Unit: Tesla (T) - not milliTesla
  • Decimal: Use dot (.) as decimal separator
  • Length: 2 to 200,000 uploaded points; long sequences are processed recursively

Sampling Frequency & Time Parameters

Test Center is optimized for high-speed magnetic measurements:

Sampling Frequency 16 MHz 16,000,000 samples/second
Sampling Period (Δt) 6.25×10⁻⁵ ms 62.5 nanoseconds per point
Total Time Calculation T = (N - 1) × 6.25×10⁻⁵ ms N = number of data points

Important: The native model grid is 16 MHz. The compatibility endpoint resamples other grids to 16 MHz for inference, but the strict manuscript-evaluation endpoints should be used when measured historical H and exact evaluation control are required.

Temperature Control

The temperature slider allows you to specify operating conditions:

  • Range: 25°C to 70°C
  • Default: 25°C (room temperature)
  • Auto-update: Changing temperature automatically triggers AI re-prediction with new thermal parameters
  • Effect: Influences the predicted H trajectory and the derived magnetic-energy metric

Model Scope

The browser Test Center exposes the independent native single-sequence cold-start family:

  • Four browser materials: 3C92, 3C95, FEC014, and T37 each use a material-specific cold-start checkpoint with one zero H placeholder
  • Scientific APIs: remain separate and accept measured historical H for the original evaluation protocols

Analysis Results

Test Center provides three visualization panels:

  • Magnetic-Energy Exchange Rate Density (W/m³): Horizontal bar chart calculated from the input B trajectory and AI-predicted H trajectory over the selected interval. It represents core-loss density only for a closed steady-state cycle.
  • Magnetic Flux Density B (T): Time-domain display of the uploaded B-field sequence.
  • Field Strength H (A/m): AI-predicted material-specific H-field response under the native cold-start protocol.

Magnetic-Energy Calculation Method

The displayed interval metric is obtained by integrating the predicted H trajectory along the submitted B trajectory and dividing by the interval duration:

p_interval = |∫ H dB| / Δt_interval

At the native 16 MHz sampling rate, adjacent samples are separated by 62.5 ns. The numerical result is an interval magnetic-energy exchange rate density in W/m³. Only when the interval is a closed steady-state cycle does the loop integral represent irreversible hysteresis loss and the rate density become core-loss density; a non-closed transient interval also contains reversible energy exchange and the change in stored magnetic energy.

Design Center

Overview

The Design Center is the main workspace for designing magnetic components with real-time simulation capabilities. Unlike the Test Center (which analyzes existing data), the Design Center simulates inverter operation and calculates magnetic behavior based on circuit parameters and core geometry. It exposes dedicated 3C92, 3C95, FEC014, and T37 cold-start checkpoints; every model uses the native 1-known/999-predicted protocol with a single zero H anchor and therefore requires no measured historical H trajectory.

To reproduce the reference website numerically, the Design Center sends the points already produced by the browser simulation directly to the model instead of interpolating them to 16 MHz. The page retains 10 points per switching period, so the effective Design Center sampling rate is 10 times the selected switching frequency (0.75 MHz at the default 75 kHz). Predictions use consecutive, non-overlapping 1,000-point windows: the first window starts from H=0, and each later window receives the preceding window's final H as its boundary state. A short final window follows the reference site's padding-and-trimming rule. This compatibility path is separate from the fixed-16-MHz scientific evaluation API.

Core Parameters

  • R (Outer Radius): User-defined outer radius of the toroidal core, measured in mm (Range: 1-500)
  • r (Inner Radius): User-defined inner radius of the toroidal core, measured in mm (Range: 0-400 and r < R)
  • d (Height/Thickness): User-defined height or thickness of the toroidal core, measured in mm (Range: 1-2000)
  • N (Number of Turns): The number of wire turns in the winding (Range: 5-200)
  • Effective Cross-Sectional Area (Ae): Automatically calculated as Ae = (R - r) × d / 100, displayed in cm²
  • Effective Magnetic Path Length (Le): Automatically calculated as Le = π × (R + r), displayed in mm
  • Inductance (L): Core geometry and winding turns are supplied by the user. The AI model reconstructs H from the resulting B trajectory; material constants are not inferred from the display defaults.

Operating Conditions

Configure inverter and grid parameters for simulation:

  • Topology: The Design Center uses the single-phase converter topology
    • Single-Phase Full Bridge
  • DC Voltage: Input DC voltage (200-800V)
  • Switching Frequency: Inverter switching frequency (5-100kHz)
  • Filter Inductance (L): Grid-side filter inductance in mH (0-1.5)
  • Filter Capacitance (C): Filter capacitance in μF (0-20)
  • Grid Voltage: AC grid voltage in V (110-380)
  • Grid Frequency: Grid frequency in Hz (50-60)
  • Power: Target power output in W (0-15000)
  • Grid Impedance: Line impedance in Ω (0-1)
  • Harmonics: Optional injection of 3rd, 5th, and 7th harmonics (0-5%)

Visualization Charts

  • Grid & Inverter Voltage: Dual-axis chart showing grid voltage (cyan) and inverter output voltage (orange) over time. Includes draggable handle for panning both synchronized charts.
  • Inductor Voltage & Flux Linkage: Shows inductor voltage V_L (green) and magnetic flux linkage (yellow). Supports click-and-drag selection to trigger AI predictions on selected flux regions.
  • Magnetic-Energy Result: Bar chart comparing interval magnetic-energy exchange rate density for the selected materials. Click a bar to activate that material's B-H curve visualization.
  • Magnetic Flux Density (B): Displays B-field characteristics calculated from selected flux regions.
  • Field Strength (H): AI-predicted H-field based on B and material properties.

Flux Selection for AI Prediction

In the Inductor Voltage & Flux Linkage chart:

  1. Click and drag horizontally to select a region of the flux curve
  2. The selected region is highlighted with an orange bounding box
  3. The system automatically calculates B = Flux / (Ae × N)
  4. AI prediction is triggered to generate corresponding H-field
  5. The interval magnetic-energy exchange rate density is calculated for the selected region; it is core-loss density only when the region forms a closed steady-state cycle
  6. Note: Selection clears when zooming or panning charts

Chart Synchronization

The voltage and flux charts are synchronized for consistent analysis:

  • Zoom Sync: Zooming (mouse wheel) on either chart synchronizes both x-axes
  • Pan Sync: Horizontal panning on either chart updates both views simultaneously
  • Draggable Handle: Blue vertical handle on voltage chart allows synchronized panning of both charts
  • Auto-reset: Any zoom/pan operation resets the flux selection to ensure data validity

Power Control Parameters

The simulation includes a PI controller for power regulation:

  • Kp (Proportional Gain): Default 0.00004, adjustable range 0-0.0001
  • Ki (Integral Gain): Default 0.8, adjustable range 0-2
  • Controller adjusts modulation index to track target power: Δm = Kp(P* - P) + Ki∫(P* - P)dt

Simulation Details

The Design Center runs a time-domain circuit simulation with the following characteristics:

  • Simulation Duration: 5 grid cycles
  • Time Step: Determined by switching frequency (100 steps per switching period)
  • Integration Method: Explicit Euler for inductor current and flux linkage
  • PWM Strategy: Sinusoidal PWM (SPWM) with triangular carrier
  • Three-Level Modulation: Phase Disposition (PD) PWM for T-Type topology

Model Libraries

Pre-trained Models

The browser Test Center, Design Center, and Model Libraries expose 3C92, 3C95, FEC014, and T37. Their cold-start checkpoints accept B-only input, while the separate scientific API retains the complete research registry and its measured-history evaluation protocols.

Available Material Models

3C92

Five-layer compact TCN with a two-layer BiLSTM; 497,793 trainable parameters.

3C95

Seven-layer TCN-BiLSTM model used for cross-frequency evaluation.

FEC014

Uses increased TCN channels and BiLSTM hidden dimensions for complex hysteresis.

T37

Adds the second flux-increment feature ddB to the standard input representation.

Model Architecture

  • Type: Temporal Convolutional Network with a bidirectional LSTM and fully connected regression layers
  • Parameters: 497,793-2,512,593 trainable parameters, depending on the material
  • BiLSTM Hidden Size: 96-208 units per direction, depending on the material model
  • Regression Head: 128 hidden units followed by pointwise H output
  • Input Features: B, dB, temperature, known H, and mask; the T37 model additionally uses ddB
  • Output: Reconstructed H-field sequence (A/m) and magnetic-energy post-processing

Temperature Dependence

All models include temperature as an input over the measured 25-70°C range. The neural network learns the relationship between temperature, B, and the corresponding H trajectory.

Model Training

Offline Training of Custom Models

This public website is an inference release and does not include model-training scripts, training datasets, or browser training. Custom models for proprietary materials or additional operating ranges must be trained in a separately maintained offline environment. The Model Libraries page lets users inspect 3C92, 3C95, FEC014, and T37 transfer-learning baselines and edit a locally saved hyperparameter configuration for reference.

Dataset Format

A compatible external training workflow can use three CSV files with matching dimensions:

  • H.csv: Magnetic field strength in A/m, shape (N, M)
  • B.csv: Magnetic flux density in Tesla, shape (N, M)
  • T.csv: Temperature in Celsius, shape (N, 1)

Where N is the number of samples and M is the time series length. All three files must have the same number of samples (N). Data is loaded using comma-separated values.

Offline Training Process

  1. Prepare H.csv, B.csv, and T.csv and keep the acquisition sequences separated before sliding-window extraction
  2. Select 3C92, 3C95, FEC014, or T37 as the transfer-learning initialization; the Model Libraries selector shows the exact architecture metadata for each baseline
  3. Edit epochs, learning rate, batch size, validation split, window stride, loss function, and frozen layers in Model Libraries; the reference configuration is saved in the browser
  4. Implement and run training in a separately maintained Python/PyTorch environment
  5. Review the saved loss, sequence-error, and energy-error records
  6. Use the generated PyTorch checkpoint (.pth) and training report; the website provides no browser download endpoint

Hyperparameters

Epochs 10 - 1000 Number of complete passes through dataset
Learning Rate 0.0001 - 0.1 Step size for gradient descent optimization
Batch Size 8 - 128 Samples processed before weight update
Validation Split 0.1 - 0.4 Fraction of data reserved for validation
Window Stride 1 - 1000 Sliding window step (window size fixed at 1000)
Loss Function MSE / RMSE / Energy Error Optimization objective
Frozen Layers 0 - 3 Number of initial layers frozen during fine-tuning

Training Metrics

  • Training/Validation Loss: Loss curves recorded by the offline training run (blue = training, green = validation)
  • RMSE: Root Mean Square Error percentage vs. baseline model
  • Energy Error: Relative discrepancy between measured- and predicted-H magnetic-energy integrals over the defined evaluation interval

Transfer Learning

The offline workflow uses the selected base checkpoint to accelerate convergence:

  • Base model weights are loaded as starting point
  • Frozen layers preserve low-level feature extraction
  • Unfrozen layers adapt to new material characteristics
  • Particularly effective for materials similar to base ferrites

Export & Integration

Offline Artifacts

A separate offline training workflow should write trained checkpoints and analysis records to its configured output directory. The inference website does not generate or expose training artifacts.

Model Export

  • Model Weights (.pth): PyTorch checkpoint containing trained parameters for deployment in a compatible Python/PyTorch environment.
  • Training Report: Saved experiment records can include:
    • Training and validation loss curves
    • Sequence-error and energy-error progress charts
    • Hyperparameter configuration table
    • Final performance metrics
    • Training time and convergence statistics

API Integration (Test Center)

The Test Center uses the following REST API endpoint for predictions. You can integrate this into your own applications:

POST /api/predict-cold-start
Content-Type: application/json

{
  "materialId": 3,             // 1..4 maps to 3C92, 3C95, FEC014, T37
  "sample": {
    "B": [0.001, 0.002, ...],  // Array of B values in Tesla
    "T": 25,                    // Temperature in Celsius
    "real_time": 0.0000625,    // Endpoint span in seconds
    "duration_semantics": "endpoint_span"
  }
}

Response:

{
  "H_pred": [12.5, 13.2, ...],  // Predicted H values in A/m
  "core_loss": 2.34             // Interval magnetic-energy exchange rate density in W/m^3
}

Data Retention Policy

The public inference service does not retain uploaded Test Center CSV data. Browser-based fine-tuning is disabled, and training tools are not included in this deployment.

Troubleshooting

Common Issues

Test Center: "No valid data found in file"

  • Ensure the CSV is single-line format (no row headers)
  • Check that values are comma-separated without extra spaces
  • Verify decimal points use dots (.) not commas
  • Ensure file extension is .csv and encoding is UTF-8
  • Check that B values are in Tesla, not milliTesla

Test Center: Unexpected Magnetic-Energy Metric

  • Verify data was sampled at 16 MHz (6.25×10⁻⁵ ms intervals)
  • If using different sampling rate, resample data before upload
  • Use one or more complete steady-state cycles when interpreting the result as core-loss density
  • Check temperature setting matches measurement conditions

Design Center: Simulation Not Updating

  • Check that R > r (outer radius must be larger than inner radius)
  • Verify all parameters are within valid ranges
  • Ensure DC voltage > Grid voltage for proper operation
  • Check browser console for JavaScript errors

AI Prediction Failed

  • Confirm the local website process is running and the browser can reach its API endpoint
  • Long selections require multiple sequential model windows; allow the request to finish or choose a shorter interval if it times out
  • Verify that the selected 3C92, 3C95, FEC014, or T37 cold-start checkpoint is available and integrity-verified by the server
  • Check browser console for detailed error messages

Performance Tips

  • Test Center: For large datasets (>100k points), consider downsampling to improve prediction speed
  • Design Center: Long selections are supported but take proportionally longer because their model windows are evaluated sequentially
  • General: Clear browser cache if charts fail to render or display outdated data
  • Mobile: Use desktop browser for best experience; mobile view is limited
