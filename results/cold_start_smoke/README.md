# Real-checkpoint cold-start smoke outputs

This directory is generated by
`scripts/generate_cold_start_smoke_results.py`. The input B trajectory is the
project-generated synthetic fixture in
`examples/data/synthetic_window_A_1000.csv`; it is not private training data or
an accuracy benchmark.

The four 1,000-point CSV files verify that every browser material can load its
own hash-checked checkpoint and return finite H values. The 2,200-point 3C92
case additionally exercises recursive multi-window stitching. Exact output
hashes, bounds, energy-quantity labels, and stitching metadata are recorded in
`smoke_summary.json`.
