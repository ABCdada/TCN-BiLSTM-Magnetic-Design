# Reproducible synthetic examples

This directory is generated by
`scripts/generate_reproducible_bundle.py`. It contains 16 deterministic
software-verification cases:

- all supported history/prediction modes for Materials A, B, D, and E;
- the dedicated `1-999` cold-start family for Materials A--E; and
- one Material-A example for each supported converter topology.

For each case, `inputs/` stores the JSON request, `outputs/` stores the complete
JSON response, and `timeseries/` stores a point-by-point CSV suitable for
MATLAB, Origin, Excel, or Visio. `figures/` contains representative editable
SVG plots and `tables/` contains compact smoke-test summaries.

`manifest.json` records the environment, checkpoint-manifest hash, and SHA-256
hashes of the case artifacts. Validate it against
`schemas/reproducible-example-manifest.schema.json`.

These waveforms are synthetic. They contain no measured continuation of `H`,
so the files deliberately report no RMSE, P95, or loss-error accuracy metric.
Finite execution demonstrates software connectivity only.

Regenerate from the repository root:

```bash
python scripts/generate_reproducible_bundle.py \
  --project-root . \
  --output results/reproducible_examples \
  --device cpu
```
