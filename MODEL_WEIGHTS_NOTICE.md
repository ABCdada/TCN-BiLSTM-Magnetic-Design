# Model checkpoint notice

The MIT license covers the original software in this repository. It does not
automatically license training data or trained checkpoint files.

The full deployment package contains five scientific checkpoints and four
browser cold-start checkpoints. Their filenames, sizes, parameter counts, and
SHA-256 hashes are recorded in `weights/manifest.json` and
`weights/cold_start_manifest.json`.

Checkpoint files should be published or redistributed only when the publisher
owns them or has permission to distribute them.
